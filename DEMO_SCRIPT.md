# Five-minute demo

**0:00 — Orient.** “RAG Lab turns an invisible pipeline into something we can inspect.” Point out the Active Pipeline bar and nine live stages.

**0:35 — Ingest.** Open Ingest and upload a report. Show the page beside its layout tree, table region and removed footer.

**1:05 — Chunk.** Open Chunking. Drag size and overlap; call out colored chunks, overlap stripes, cut line, histogram and warnings.

**1:45 — Flip the chunker.** Change Recursive to Semantic. Follow the amber ripple down the rail. When it completes, read the “What changed?” summary and point to the new count and quality.

**2:25 — Embed and index.** Select NVIDIA NV-Embed-v2 or Hugging Face BGE-M3. Show clusters and the query point, then move to HNSW and describe approximate search.

**3:05 — Retrieve and rerank.** Show the nearest-match trace and rank-change arrows. Turn on Compare pipelines to contrast A and B.

**3:45 — Generate.** Select Ollama · NVIDIA Nemotron. Explain the color-coded prompt and click the citation back to page 8.

**4:25 — Evaluate.** Show faithfulness, recall, relevance and latency. Explain that a good answer is not enough: each failure must be attributable to a stage.

**4:55 — Close.** “Every knob is global, every consequence is visible, and the evidence never loses its path home.”
